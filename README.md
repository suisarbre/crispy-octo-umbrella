# crispy-octo-umbrella

브라우저에서 도는 확률 기반 분대 전술 게임. 정적 페이지 + WASM, 서버 없음.
무엇을 만들고 무엇을 안 만드는지는 [DESIGN.md](DESIGN.md).

## 조작

- 아군 클릭: 선택. 행동 범위 밖의 빈 칸을 누르면 선택 해제
- 유닛을 길게 누르거나 마우스를 올리면 체력이 보인다
- 밝은 점 클릭: 이동 (행동 1)
- 적 클릭: 사격 (그 유닛의 턴이 끝남). 마우스를 올리면 명중률과 내역이 보인다.
- B: 잠복 (잠복 개조 유닛만)
- Space: 턴 종료

## 월드 (`world.html`)

전투와 아직 이어지지 않은 첫 조각이다.

- `◆` 부대 (아군은 초록, 인류는 주황), `○` 거점, `◉` 본진, `·` 길
- 아군 부대 클릭: 선택. 겹쳐 있으면 누를 때마다 다음 부대
- 길 위의 칸 클릭: 그곳으로 이동. 길 밖을 누르면 선택 해제
- Space: 하루 넘기기. 양쪽이 동시에 움직인다
- 칸을 길게 누르거나 마우스를 올리면 거기 무엇이 있는지 보인다

## 글리프

| | |
| --- | --- |
| `ψ` 저격 | 안 움직이고 쏘면 거리 감점이 없고 조준이 오른다 |
| `θ` 화력 | 4칸 안에서는 사격이 행동 1만 쓴다 |
| `λ` 잠복 | 땅에 숨는다 (`∩`). 숨어 있다가 쏘면 엄폐를 무시한다 |
| `ν` 원형 | 개조 없음 |
| `h` 보병, `&` 중계기 | |
| `s` 탐지기 | 6칸 안의 숨은 유닛을 드러낸다. 못 싸운다 |
| `m` 연막병 | 연막(`≈`)을 던진다. 연막 너머는 2칸까지만 보인다 |
| `H` 방패병 | 가장 가까이 보이는 적 쪽으로는 항상 엄폐 |

## 빌드

```sh
rustup target add wasm32-unknown-unknown   # 처음 한 번
./build.sh
python3 -m http.server -d www 8000
```

```sh

```
