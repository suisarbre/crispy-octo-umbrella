전략 전구 (80×52 헥스)

        

          좌드래그 / WASD : 부드러운 지도 이동
          마우스 휠 / M : 커서 기준 줌 / 전체 보기
          우클릭 : 즉시 행군 (선택 모드 실행)
          Shift+우클릭 / 좌클릭 : 4종 명령 메뉴
          1~4 : 이동 · 매복 · 주둔 · 정찰 모드
          Space / N : 실시간 재생·정지 / +1일
          F / 미니맵 : 분대 포커스 / 즉시 점프
          G / Esc : 보급권 정비·개조 / 취소
        

        
▲ 산맥은 통과 불가(길목 형성), ═ 도로는 속도 2배 + 보급권 연장. 매복 교전 시 1턴 조준+15·엄폐 무시 선제 기습!

        
거점 목표: ┴ 중계탑은 중계기(&) 파괴 시 즉시 승리, 보급대 차단은 생체질 대량 보상, 인류 본진(◉) 점령 시 캠페인 승리!

      

      

        
전술 전투 (XCOM 조작)

        

          Tab : 분대원 / 표적 순환
          1 : 공격 조준 → 재입력 사격
          2 / O : 경계 (이동 적 대응사격)
          3 / H : 엄호 (방어+30·치명 면역)
          4 / G : 파열탄 (3×3 엄폐 파괴·피해2)
          5 / F : 병과 스킬 (표식/제압/잠복/재생)
          6 / R : 좌측 가장자리 후퇴
          Space : 턴 종료 / Esc : 취소
        

      

      

        
엄폐 · 측면 치명타 · 베테랑

        
엄폐 없는 측면 노출(◈) 표적은 치명타 50%(피해 +2)! 대원이 살아남고 적을 처치하면 숙련 → 정예 → 고참으로 진급해 조준·최대체력·치명타·경계 명중이 영구 상승합니다.

      

      

        
제국 특수 병과

        
& 중계기(생존 시 제국 협공) · H 방패병(정면 90° −40 엄폐) · s 탐지기(6칸 잠복 탐지) · m 연막병(3×3 시야 차단)
